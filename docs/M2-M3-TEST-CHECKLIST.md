# M2/M3 功能测试清单

## 测试环境
- 线上地址：https://chuchu-tian.github.io/family-health-record/
- 测试账号：使用你的家庭成员账号

## M2 功能测试：AI 识别

### 测试步骤
1. 登录应用
2. 进入某个成员的时间线页面
3. 点击「＋ 新增病历」
4. 填写基本信息（疾病名称、就诊日期等）
5. 上传一张病历照片或检查报告（支持 JPG/PNG/PDF）
6. 上传成功后，点击进入该病历的详情页
7. 点击附件下方的「🤖 AI 识别」按钮
8. 等待 AI 分析（调用京东云 Claude 网关）
9. 查看提取的结构化信息：
   - 疾病名称
   - 诊断
   - 医院/科室/医生
   - 用药信息
   - 健康指标（血压、血糖、体重等）
   - 费用
10. 核对识别结果（如有错误，取消后手动填写）
11. 点击「确认并应用到病历」
12. 验证信息已自动填充到病历字段

### 预期结果
- ✅ AI 识别按钮可点击
- ✅ 识别过程中按钮显示「⏳ 识别中…」并禁用
- ✅ 识别结果以 JSON 形式展示，可确认或取消
- ✅ 应用后病历字段自动更新
- ✅ 健康指标自动保存到 health_metrics 表
- ✅ 未登录状态下调用 Edge Function 返回 401（安全边界）

## M2 功能测试：全文搜索

### 测试步骤
1. 在首页点击「🔍 搜索」按钮
2. 输入关键词，例如：
   - 疾病名称（如「感冒」）
   - 诊断内容（如「病毒性感染」）
   - 医院名称（如「瑞金医院」）
   - 医生姓名
3. 输入后自动搜索（300ms 防抖，无需点按钮）
4. 查看搜索结果列表
5. 点击某条结果查看详情

### 预期结果
- ✅ 搜索框可正常输入
- ✅ 搜索结果匹配关键词
- ✅ 结果按就诊日期倒序排列
- ✅ 点击结果可跳转到详情页
- ✅ 无结果时显示「未找到相关病历」

## M3 功能测试：健康指标趋势图

### 测试步骤
1. 进入某个成员的时间线页面
2. 点击「📊 健康指标」按钮
3. 查看指标类型选择器（血压、血糖、体温等）
4. 选择一个指标类型（如「收缩压」）
5. 查看折线图展示：
   - X 轴：测量日期（首末两个日期）
   - Y 轴：指标数值（最小值与最大值）
   - 数据点连线
6. 查看图表下方的数据列表（倒序，最新在前）
7. 切换不同指标类型
8. 如果没有数据，显示「暂无数据」提示

### 预期结果
- ✅ 指标选择器显示所有可选类型
- ✅ 折线图正确绘制
- ✅ 数据列表显示数值、单位与测量日期
- ✅ 异常值以「异常」标签标识
- ✅ 切换指标类型图表实时更新

## 数据验证

### 验证数据库
在 Supabase Dashboard → Table Editor 中检查：
1. `health_metrics` 表是否有数据
2. `records` 表的 `search_vector` 列是否已生成
3. RLS 策略是否正常工作（未登录读取 health_metrics 应被拒绝）

### 验证 Edge Function
在 Supabase Dashboard → Functions → analyze-attachment 中检查：
1. 函数状态：Active
2. Invocations：有调用记录
3. Logs：无错误日志
4. Secrets 已配置：`JD_CLOUD_API_KEY`（必填）、`JD_CLOUD_ENDPOINT`（可选，默认京东云网关）

## 性能测试
- 搜索响应时间 < 1 秒
- AI 识别响应时间 < 10 秒（取决于图片大小和网络）
- 趋势图渲染 < 500ms

## 已知限制
- AI 识别需要京东云 API 密钥配置正确
- 仅支持中文病历识别
- 趋势图最多展示最近 100 个数据点
- 折线图为 Canvas 绘制，暂不支持数据点悬停查看明细
