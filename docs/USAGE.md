# 使用手册（给全家人看）

网站地址：**https://chuchu-tian.github.io/family-health-record/**

这是我们家自己的健康记录本：谁生了病、医生怎么说、吃什么药、化验单照片，都记在这里，全家人都能看。

> ⏳ 如果打开显示「云端还没开通」，说明管理员还在准备中，请等通知。

## 一、把它变成手机上的一个"App"

只需做一次，以后点图标就能打开。

**安卓手机（Chrome 浏览器）**
1. 打开上面的网址
2. 点右上角「⋮」菜单
3. 点「添加到主屏幕」→ 确定

**iPhone（Safari 浏览器）**
1. 打开上面的网址
2. 点底部中间的「分享」按钮（方框加箭头）
3. 往下找「添加到主屏幕」→ 添加

**电脑（Windows / Mac）**
直接用浏览器打开网址，收藏到书签即可。

## 二、登录

- 用**自己的邮箱和密码**登录（管理员发给你的那个）
- 登录一次就长期有效，以后打开不用再输
- 忘记密码？直接找管理员重置，不用自己操作

## 三、记一条病历（爸妈版，三步就够）

1. 点绿色大按钮「**＋ 新增**」
2. 填「**得了什么病**」（日期已经自动填好今天，不用动）
3. 点「**拍照或选择图片**」拍下化验单/病历本 → 点「**保 存**」

完事了！其他内容都不用填，以后谁想补充都可以。

想多记一点的话，点「展开更多」还能填：医生诊断、吃什么药、忌口、花了多少钱、下次复诊日期等——都是选填。

## 四、看家人的病历

- 首页点**谁的头像**就看谁的记录
- 全家人都能互相查看
- 但**只能修改自己的**记录（管理员可以帮所有人修改补充）

## 五、复诊提醒

记录里填了「下次复诊日期」的话，复诊前 14 天内首页顶部会出现提醒横幅。

注意：这是**打开应用才能看到**的提醒，不会往手机推送通知，所以记得时常打开看看。

## 六、隐私放心

- 必须登录才能看到任何内容
- 别人就算知道网址，没有账号密码什么也看不到
- 照片存在受保护的云端空间，不登录拿不到

## 七、常见问题

| 问题 | 办法 |
|---|---|
| 照片传不上去 | 多半是网络不好。你填的内容**不会丢**，检查网络后再点一次「保 存」 |
| PDF 传不上去 | 单个 PDF 最大 20MB，太大的先压缩 |
| 删除的记录能找回吗 | **不能**，删除前会弹确认框，请看清再点 |
| 想换头像/称呼 | 找管理员改 |
| 登录不上 | 检查邮箱密码有没有输错；还不行找管理员 |
